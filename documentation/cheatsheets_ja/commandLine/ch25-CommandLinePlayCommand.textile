h2. Command line - play command

@play@ コマンドは Gradle の薄いシェルラッパーです。各サブコマンドは
@play1@ タスクグループ内の Gradle タスクに委譲されます。

*classpath*
算出されたランタイムクラスパスを表示します。

*secret*
HMAC および暗号化に使われる秘密鍵を生成します。

*new*
新しいアプリケーションを作成します (任意のディレクトリから実行可能。Nuxt 4
フロントエンドスケルトンが必要な場合は @--frontend@ を指定)。

*modules*
このアプリケーションで読み込まれるモジュールを表示します。

*javadoc*
アプリケーションの Javadoc を生成します。

*autotest*
全てのアプリケーションのテストをヘッドレスで実行します。

*clean*
@tmp/@ ディレクトリを削除します。

*test*
現在のシェルでアプリケーションをテストモードで実行します。

*precompile*
本番用に全ての Java ソースとテンプレートをプリコンパイルします。

*bundle*
自己完結型の配布 ZIP をビルドします (エイリアス: @dist@)。

*run*
現在のシェルでアプリケーションを実行します (開発モード)。

*start*
バックグラウンドでアプリケーションを起動します。

*stop*
実行中のアプリケーションを停止します。

*restart*
実行中のアプリケーションを再起動します。

*status*
実行中のアプリケーションの状態を表示します。

*out*
@logs/system.out@ をリアルタイムで表示します。

*pid*
実行中のアプリケーションの PID を表示します。

*evolutions*
データベースの evolutions を適用します。

*version*
フレームワークのバージョンを表示します。

*help*
使用方法を表示します。
