h2. Command line - play command

The @play@ command is a thin shell wrapper around Gradle. Each subcommand
delegates to a Gradle task in the @play1@ task group.

*classpath*
Print the resolved runtime classpath

*secret*
Generate a new secret key, used for HMAC and encryption

*new*
Scaffold a new application (run from any directory; pass @--frontend@ for the
Nuxt 4 frontend skeleton)

*modules*
Print the modules that will be loaded for this app

*javadoc*
Generate the application's Javadoc

*autotest*
Run all application tests headlessly

*clean*
Delete the @tmp/@ directory

*test*
Run the application in test mode in the current shell

*precompile*
Precompile all Java sources and templates for production

*bundle*
Build a self-contained deployment ZIP (alias: @dist@)

*run*
Run the application in the current shell (development mode)

*start*
Start the application in the background

*stop*
Stop the running application

*restart*
Restart the running application

*status*
Print the running application's status

*out*
Tail @logs/system.out@

*pid*
Show the PID of the running application

*evolutions*
Apply database evolutions

*version*
Print the framework version

*help*
Show usage
