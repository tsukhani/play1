~ Name:
~ ~~~~~
~ new -- Create a new application
~
~ Synopsis:
~ ~~~~~~~~~
~ play new <name> [--frontend] [--dest=<path>]
~
~ Description:
~ ~~~~~~~~~~~~
~ Scaffold a new Play application named <name> in the current working directory
~ (or at <path> if --dest is supplied). Backed by the playNewApp Gradle task.
~
~ The created application contains a default welcome page and an
~ application-skel-derived build.gradle.kts ready to run via:
~     cd <name> && play run
~
~ Options:
~ ~~~~~~~~
~ --frontend:
~ Scaffold a Nuxt 3 + Tailwind CSS frontend in <app_path>/frontend alongside
~ the Play backend. Adds an ApiController with a /api/status endpoint and
~ wires the route into conf/routes. Currently only Nuxt is supported.
~ For example: play new myApp --frontend
~
~ Start the frontend afterwards with: cd myApp/frontend && pnpm install && pnpm dev
~
~ --dest=<path>:
~ Scaffold into <path> instead of <cwd>/<name>. Relative paths resolve against
~ the current working directory.
~
