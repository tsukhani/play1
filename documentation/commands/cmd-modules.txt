~ Name:
~ ~~~~~
~ modules -- Display the computed modules list
~
~ Synopsis:
~ ~~~~~~~~~
~ play modules
~
~ Description:
~ ~~~~~~~~~~~~
~ Print the modules that would be loaded for this application. Walks the
~ play1 { modules(...) } DSL in build.gradle.kts plus the framework's auto-loaded
~ modules (docviewer in dev, testrunner in test).
~
~ Options:
~ ~~~~~~~~~
~ -PplayId=<id>:
~ Use this play.id when computing the module list (mirrors %prefix selectors
~ in conf/application.conf).
~
